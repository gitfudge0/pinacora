# Code of Conduct

Pinacora's issues, pull requests, and other project spaces should be welcoming and useful to everyone.

Be respectful, assume good intent where reasonable, and keep criticism focused on ideas and behavior. Explain disagreements constructively. Respect people's privacy, identities, experience levels, and accessibility needs.

Harassment, discriminatory language, threats, sexualized attention, doxxing, spam, and deliberate disruption are not welcome. Do not publish someone else's private information without permission.

The maintainer may remove inappropriate content, close discussions, or restrict participation to protect the project community. Actions depend on the circumstances; this policy does not promise a particular enforcement process or response time.

For concerns, contact the [maintainer through their GitHub profile](https://github.com/gitfudge0) using an available contact method. If no private channel is listed, request one without posting sensitive details in a public issue. For software vulnerabilities, follow [SECURITY.md](SECURITY.md).
